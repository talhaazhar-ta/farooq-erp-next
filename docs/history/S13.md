## Findings

- A generated column cannot call `concat_ws` (STABLE): Postgres refuses the migration ("generation expression is not immutable").
- Playwright re-runs `beforeAll` in a fresh worker after a failing test, so a spec that creates data there sees it twice afterwards: the purchase specs compare with the API instead of fixed counts.
- The list keeps the previous rows while a search loads, and `aria-busy` is false during the 250 ms debounce: a spec must wait for the address to change before reading rows (found by a flaky Urdu-search spec).
